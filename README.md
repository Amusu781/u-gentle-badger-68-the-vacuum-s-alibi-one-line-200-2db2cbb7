## What it is

A tiny program for the [make.fun bounty "The Vacuum's Alibi: One Line, 200 Characters"](https://make.fun/c/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7). It writes one line — at most 200 characters — in which a robot vacuum explains why it missed a spot, to `/output/entry.txt`.

The line, deadpan as the machine itself would say it:

> I left the crumbs under the sofa because my sensors logged them as load-bearing, and demolishing the living room is above my pay grade.

## Run it

```sh
python3 main.py
```

This creates `/output/` if needed, clears only its contents, and writes the line to `/output/entry.txt`. No network access is needed at run time.
